# Xiaomi LivePhoto Splitter & Web Viewer / 小米实况图片拆分脚本与网页支持示例

A Node.js script to extract JPEG and MP4 from Xiaomi Motion Photos, plus a web demo showing how to display them with hover-to-play interaction.

Node.js 脚本将小米实况图片（动态照片）拆分为 JPEG 封面图和 MP4 视频，附带网页示例展示如何实现悬停播放交互。

---

## Features / 功能

- **Batch extraction / 批量提取** — Automatically scan and extract all motion photos from the `images/` folder. / 自动扫描并提取 `images/` 文件夹中的所有动态照片。
- **Smart splitting / 智能拆分** — Accurately locates the JPEG end marker by searching backward from the MP4 position, avoiding false matches from embedded thumbnails. / 从 MP4 位置反向查找 JPEG 结束标记，避免被缩略图误导。
- **Hover to play / 悬停播放** — Desktop: hover to play video with sound; Mobile: long press to play. / 桌面端悬停播放视频（带声音），移动端长按播放。
- **Original aspect ratio / 原比例显示** — Images displayed at their native resolution, no cropping. / 图片按原始分辨率显示，不裁剪。
- **Staggered gallery / 错位画廊** — Artistic 3-column staggered layout with entrance animations. / 艺术感三列错位布局，带入场动画。
- **Auto-generated gallery / 自动生成相册** — The page dynamically loads from `extracted/photos.json`, no code changes needed. / 页面自动加载 `extracted/photos.json`，无需修改代码。

## How It Works / 工作原理

### The Motion Photo Format / 实况图格式

Xiaomi Motion Photos store a **JPEG still image** and an **MP4 video** concatenated into a single `.jpg` file:

小米动态照片将一张 **JPEG 静态图片** 和一段 **MP4 视频** 拼接在同一个 `.jpg` 文件中：

```
[JPEG data ... FF D9] [MP4 data ...]
```

The JPEG ends with the marker `0xFF 0xD9`, followed immediately by the MP4 data starting with an `ftyp` box.

JPEG 以 `0xFF 0xD9` 标记结尾，紧接着是以 `ftyp` 盒子开头的 MP4 数据。

### Extraction Logic / 提取逻辑

The extraction script (`extract.js`) uses a two-step approach:

提取脚本采用两步策略：

1. **Find MP4 start / 定位 MP4 起始位置** — Scan the file for the `ftyp` MP4 signature with a valid box size header. / 扫描文件，寻找带有有效 box size 头部的 `ftyp` MP4 特征码。
2. **Find JPEG end / 定位 JPEG 结尾** — Search **backward** from the MP4 start position to find the last `0xFF 0xD9` marker. / 从 MP4 起始位置**反向**查找最后一个 `0xFF 0xD9` 标记。

This backward-search strategy is critical because JPEG files often contain embedded thumbnails with their own `FF D9` markers. Searching from the MP4 position backward ensures we find the **true end of the main image**, not a thumbnail.

这种反向搜索策略至关重要，因为 JPEG 文件通常包含内嵌缩略图，它们也有自己的 `FF D9` 标记。从 MP4 位置反向搜索确保我们找到的是**主图的真正结尾**，而不是缩略图。

```
File / 文件: [JPEG main image ... FF D9] [JPEG thumbnail ... FF D9] [MP4 video ...]
                                                                       ^
                                               Start searching backward from here
                                               从这里开始反向搜索
```

### Web Display / 网页展示

The `index.html` page works as follows:

`index.html` 页面的工作流程：

1. Fetches `extracted/photos.json` (auto-generated by the script) / 获取 `extracted/photos.json`（由脚本自动生成）
2. Renders each photo as a card with the cover image and video / 将每张照片渲染为包含封面图和视频的卡片
3. On hover/long-press: fades the image out, plays the video with audio / 悬停/长按时：淡出图片，播放带声音的视频
4. On leave: fades back to the still image / 离开时：淡出视频，恢复静态图片

## Getting Started / 快速开始

### Prerequisites / 前置要求

- [Node.js](https://nodejs.org/) — Required for running the extraction script. / 运行提取脚本所需。
- A modern browser (Chrome, Firefox, Safari, Edge) — For viewing the gallery. / 用于查看相册的现代浏览器。

### Installation / 安装

```bash
# Clone the repository / 克隆仓库
git clone https://github.com/your-username/live-photo.git
cd live-photo
```

### Usage / 使用方式

**Step 1: Prepare photos / 准备照片**

Put your Xiaomi Motion Photos (`.jpg` files taken with motion photo mode) into the `images/` folder.

将你的小米动态照片（使用动态照片模式拍摄的 `.jpg` 文件）放入 `images/` 文件夹。

**Step 2: Extract / 提取**

```bash
node extract.js
```

The script will scan all images in `images/`, extract the cover and video from each, and generate `extracted/photos.json`.

脚本会扫描 `images/` 中的所有图片，提取每张的封面图和视频，并生成 `extracted/photos.json`。

**Step 3: Start a local server / 启动本地服务器**

```bash
npx serve .
# or / 或者
python -m http.server 8000
```

**Step 4: Open in browser / 在浏览器中打开**

Visit http://localhost:3000 (serve) or http://localhost:8000 (Python) to view the gallery.

访问 http://localhost:3000（serve）或 http://localhost:8000（Python）查看相册。

### Output Structure / 输出结构

After extraction, the `extracted/` folder will contain:

提取完成后，`extracted/` 文件夹将包含：

```
extracted/
├── photos.json              # Gallery manifest / 相册清单
├── photo1_cover.jpg         # Still image / 静态封面图
├── photo1_video.mp4         # Video / 动态视频
├── photo2_cover.jpg
├── photo2_video.mp4
└── ...
```
